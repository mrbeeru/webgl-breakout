# WebGL Breakout game

A breakout game build in webgl, and plain html, css and js.

Demo here: https://anbu-breakout.pages.dev/

<img width="1227" height="753" alt="image" src="https://github.com/user-attachments/assets/6b581ebf-bd46-469f-966d-aa0732d62108" />

From Options, you can customize: 
* Trail length.
* How many sparks appear when a brick breaks.
* The ball speed gain each time you catch it.

The game was integrated with firebase for the leaderboard functionality, but I removed that.
